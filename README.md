# Task Project

A frontend web project built with HTML, CSS, and JavaScript (with templating), showcasing multiple pages (Home, About, Contact, Pricing).  
This repository demonstrates your skills in layout structuring, responsive design, templating, and project presentation.

---

## 📂 Repository Structure

public/
├ Home.html
├ About.html
├ Contact.html
├ Price.html
└ [static assets like images, CSS]


- **Home.html**, **About.html**, **Contact.html**, **Price.html** — the main pages of the site  
- **public** folder holds CSS, images, and other static files  

---

## 🛠️ Technologies & Tools

- **HTML5 & CSS3** — semantic markup, responsive styling  
- **JavaScript** — for interactivity  
- **Templating (if used later, e.g. Nunjucks)** — to modularize layouts  
- **Bootstrap (or custom grid CSS)** — for responsive design  
- **Font Awesome** — for icons (used in the navbar and footer)  

---

## 🎯 Features & Highlights

- **Responsive Multi-page Layout**  
  Navigation bar adapts between desktop and mobile (sidebar).  
- **Contact Form Page**  
  Includes form fields: first name, last name, email, password, message, checkbox.  
- **Navbar with Active State**  
  Highlights the current page (e.g. “Contact”).  
- **Hero / Banner Imagery**  
  Each page includes a banner or illustrative image.

## ✅ How to Run / Preview Locally

You can open these pages directly in your browser:

1. Clone the repo  
    ```bash
    git clone https://github.com/priyansu57/Task.git
    cd Task
    ```

2. Serve the `public` folder (or project root) with a simple static server.  
   For example, using `http-server`:
    ```bash
    npm install -g http-server
    http-server ./public
    ```

   Then open `http://localhost:8080/Home.html` (or whichever page) in your browser.
